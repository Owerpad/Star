# Агрегатор отзывов на видеоигры

## Стек

### Backend
- Python
- FastAPI
- SQLite

### Frontend
- React
- Axios
- React Router

### Инфраструктура
- Docker
- Docker Compose

### Дополнительно
- RAWG API для получения информации об играх

---

# Цель проекта

Сделать простой сайт с отзывами на игры.

Пользователь может:
- зарегистрироваться
- войти
- просматривать игры
- искать игры
- фильтровать игры
- открывать страницу игры
- писать отзывы
- ставить оценку в звёздах
- добавлять новые игры

---

# Основные страницы

## 1. Главная страница

Содержит:
- список игр
- поиск
- фильтрацию
- сортировку

### Карточка игры
Карточка должна содержать:
- обложку
- название
- жанр
- среднюю оценку

### Поиск
Поиск:
- по названию

### Фильтрация
Фильтрация:
- по жанру
- по минимальному рейтингу

### Сортировка
Сортировка:
- по рейтингу
- по названию

---

## 2. Страница игры

Должна содержать:
- обложку
- название
- описание
- жанры
- скриншоты
- среднюю оценку
- отзывы

### Отзывы
Каждый отзыв:
- пользователь
- текст
- оценка

### Добавление отзыва
Авторизованный пользователь может:
- написать отзыв
- поставить оценку

После добавления:
- средний рейтинг обновляется

---

## 3. Страница добавления игры

Поля:
- название
- описание
- жанр

Дополнительно:

# Важные упрощения

Для уменьшения количества багов:

- использовать только SQLite
- не использовать Redux
- не использовать websocket
- не использовать сложную систему ролей
- хранить только один жанр строкой
- использовать простую JWT авторизацию
- не делать пагинацию
- не делать редактирование отзывов
- не делать загрузку файлов
- использовать URL картинок вместо локального хранения
